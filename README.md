# 🧪 Immersive Virtual Chemistry Laboratory Using Extended Reality (XR)

## 📖 Overview

The **Immersive Virtual Chemistry Laboratory Using Extended Reality (XR)** is an innovative educational platform designed to enhance chemistry learning through immersive virtual experiences. The project provides a realistic virtual laboratory environment where students can safely perform chemistry experiments using hand-tracking technology and interactive virtual equipment.

Developed using **Unity Engine** and the **Meta XR SDK**, the application enables users to interact naturally with laboratory instruments, observe chemical reactions, and gain practical knowledge without the risks, costs, and limitations associated with traditional physical laboratories.

---

## 🎯 Objectives

- Provide an immersive and interactive chemistry learning experience.
- Simulate real-world laboratory experiments in a virtual environment.
- Improve student engagement and understanding of chemistry concepts.
- Offer a safe alternative to physical laboratory experimentation.
- Reduce material consumption and laboratory maintenance costs.
- Enable repeated practice without chemical waste or safety concerns.

## 🏗️ System Architecture

The application consists of the following major modules:

1. User Interaction Module
2. Hand Tracking Module
3. Experiment Management Module
4. Chemical Simulation Module
5. Dashboard and Feedback Module
6. Audio Guidance System
7. Virtual Laboratory Environment

These modules work together to deliver an engaging and realistic virtual chemistry laboratory experience.

---

## 🧪 Implemented Experiments

### 1. Iodometric Titration
This experiment allows users to perform a complete iodometric titration procedure in a virtual environment. Users interact with laboratory equipment, observe chemical reactions, and receive real-time feedback throughout the process.

### 2. Litmus Paper Test
Users can test various solutions using virtual blue and pink litmus papers. Based on the observed reactions, the system identifies whether the solution is acidic, basic, or neutral and announces the result.
